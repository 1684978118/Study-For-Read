# Nginx Routing

This directory contains the first-release Nginx routing configuration.

## Routes

- `/api/` proxies to the Spring Boot API service at `api:8080`.
- `/admin/` serves Web Admin static assets from `/usr/share/nginx/admin`.
- `/` serves Web Reader static assets from `/usr/share/nginx/html`.
- `/health` serves the static health response from `infra/nginx/html/health.html`.

Web Reader and Web Admin client routes use static fallback files generated by Nuxt. The API remains under `/api/v1`.

## HTTPS Placeholder

The compose stack mounts `./infra/nginx/certs` to `/etc/nginx/certs` as a placeholder path for operator-managed certificates. This task does not create certificates, automate issuance, or commit private keys.

If HTTPS is enabled later, mount certificate files manually at paths matching the commented template in `conf.d/study-for-read.conf`:

- `/etc/nginx/certs/fullchain.pem`
- `/etc/nginx/certs/privkey.pem`

Do not commit `.key`, `.pem`, private key, token, password, or provider secret files.

## Logging Boundary

The Nginx access log uses a standard request log format. It does not log request bodies.
