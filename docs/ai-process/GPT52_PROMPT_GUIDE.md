# GPT-5.2 Coding Prompt Guide

把任务交给 GPT-5.2 或其他 AI 编码时，建议使用下面的提示词结构。

## 标准提示词

```text
你正在开发 D:\Codex\Study For Read Phone。

必须先阅读：
1. AGENTS.md
2. docs/ai-process/AI_DEVELOPMENT_PROCESS.md
3. 当前任务卡：docs/plans/<task-card>.md

严格限制：
- 只能修改任务卡 Allowed Files 中列出的文件。
- 禁止修改 Forbidden Files。
- 禁止批量删除文件或目录。
- 不允许复制旧项目代码。
- 修改已有文件前必须先读取文件。
- 先写测试，确认失败，再写实现。
- 验证未运行或失败时，不允许声称完成。

请执行当前任务卡。
完成后只汇报：
1. 修改文件
2. 验证命令和结果
3. 是否满足验收标准
4. 下一步建议
```

## 任务过大时的处理

如果 AI 回复中出现以下迹象，说明任务太大：

- 一次要修改超过 5 个业务文件。
- 一次同时包含后端、移动端、网页端。
- 没有测试就开始写实现。
- 自行新增未计划的依赖。
- 修改了任务卡没列出的文件。

处理方式：

1. 立刻停止当前任务。
2. 要求 AI 把任务拆成更小任务卡。
3. 每张任务卡只允许一个明确目标。
